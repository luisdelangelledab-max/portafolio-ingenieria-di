# Luis Enrique Del Ángel — Professional B2B Engineering Portfolio
## Architectural Millwork • Custom Casework • CAD/CAM • CNC Automation

This repository contains the production build of the professional B2B engineering portfolio for **Luis Enrique Del Ángel**, designed for deployment on **GitHub Pages** with $0 USD infrastructure cost.

---

### Structure
* `index.html` — Main interactive portfolio single-page application with 6 detailed case study dossiers.
* `assets/css/style.css` — High-performance responsive technical dark-mode theme.
* `assets/js/app.js` — Client-side interactive controllers (filtering, 14-block modal drawers, vector PDF viewer, comparison slider).
* `assets/images/` — Curated 4K renders, retail fixture isolation renders, and shop-floor quality control evidence.
* `assets/pdf/` — Sanitized vector shop drawings complying with ANSI/AWI 0641 standards.
* `assets/models/` — Lightweight (<15 KB) binary glTF 2.0 (`.glb`) casework digital twin for Google `<model-viewer>`.
* `.nojekyll` — Bypasses Jekyll processing on GitHub Pages to preserve all assets and paths.

---

### Deployment on GitHub Pages
1. Go to repository **Settings > Pages**.
2. Under **Build and deployment > Source**, select **Deploy from a branch**.
3. Choose branch: **`main`** / folder: **`/ (root)`**.
4. Click **Save**. The website will be live in ~60 seconds at `https://<your-username>.github.io/<repo-name>/`.
